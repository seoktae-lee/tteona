# 떠나(tteona) 마케팅 전략 — 처음부터 끝까지

> 마케팅을 배운 적 없는 개발자를 위한 실전 가이드.
> 예산 0원 전제로 시작해서, 돈을 쓸 가치가 생기는 시점까지 설계.

---

## 0. 마케팅 5분 개념 정리 (이것만 알면 됨)

마케팅은 결국 **깔때기(퍼널)** 하나다:

```
인지 (앱이 있다는 걸 안다)
 → 관심 (뭐하는 앱인지 궁금하다)
  → 설치 (다운로드)
   → 활성화 (첫 여행에서 Vlog 1개 완성)   ← ★ 떠나의 생명선
    → 유지 (다음 여행에도 켠다)
     → 추천 (친구에게 보여준다)
      → 결제 (PRO)
```

- 각 단계 사이에서 사람이 새어나간다. 마케팅 = **어느 단계가 새는지 찾아 막는 일**.
- 초보가 하는 실수: 맨 위(인지)에만 돈을 붓는 것. **아래가 새면 위에 부은 게 다 빠진다.**
- 그래서 순서는 항상: ① 활성화부터 다진다 → ② 추천(바이럴)을 만든다 → ③ 그 다음에 인지에 투자한다.

**떠나의 치트키**: 앱의 결과물(Vlog)이 그 자체로 SNS 콘텐츠다. 즉 **유저가 앱을 쓰는 행위 = 광고 집행**. 이 축을 중심에 놓는다.

## 1. 포지셔닝 — 한 문장 정하기

포지셔닝 = "누구에게, 무엇 대신, 왜 우리인가"를 한 문장으로.

> **"편집할 시간에 한 번 더 떠나. — 찍기만 하면 여행 브이로그가 완성되는 앱"**

- 경쟁 지형: 지도앱(계획) / 캡컷·VLLO(편집) / 인스타(자랑) 사이의 빈칸 = **"여행 중 기록의 자동화"**
- 절대 "지도앱"이나 "편집앱"으로 소개하지 말 것. 비교 대상이 생기는 순간 진다. 카테고리를 새로 만든다: **"자동 브이로그 앱"**.

## 2. 타겟 — 누구부터 잡을 것인가

전부를 노리면 아무도 못 잡는다. 순서대로:

| 순위 | 페르소나 | 왜 먼저인가 |
|------|---------|------------|
| 1 | **20대 중반 커플** (기념일·주말 여행, 릴스 소비층) | Vlog 욕구 최고 + 커플 태그 존재 + 둘이 깔아야 해서 설치가 2배 |
| 2 | 친구 그룹 여행 (MT·우정여행) | 실시간 위치공유+그룹채팅이 정확히 이들 문제 해결 |
| 3 | 혼행족 | 기록 욕구 강하고 커뮤니티 활동 활발 (혼행 카페·오픈채팅) |
| 4 | 일본 여행 준비자 / 방한 외국인 | ja·en 지원 — 중기 확장 카드 |

## 3. 바이럴 메커니즘 설계 — 돈 안 드는 성장 엔진 4개

**엔진 ① 워터마크 = 광고 (이미 장전됨)**
무료 Vlog의 워터마크가 릴스에 올라간다 → 보는 사람이 "이거 무슨 앱이에요?" → 댓글이 마케팅.
- 워터마크를 벌칙처럼 보이게 하지 말고 **예쁘게** 만들 것 (로고+`tteona.kr`). 부끄러운 워터마크는 업로드 자체를 막아서 엔진을 죽인다.

**엔진 ② 코스 링크 = 랜딩페이지 (이미 장전됨)**
"우리 데이트코스"를 카톡으로 공유 → OG 미리보기 → 웹에서 코스 확인 → 설치 유도. 웹 코스 페이지의 SEO 강화(로드맵 ④)가 이 엔진의 출력을 올린다.

**엔진 ③ 그룹 기능 = 강제 K-factor**
방(그룹)은 혼자 못 쓴다. 초대 코드를 받은 친구는 설치해야 한다. **"친구 초대 흐름을 3탭 이내로"** 다듬는 것이 어떤 광고보다 싸다.

**엔진 ④ 리캡(연말/시즌) 콘텐츠**
스포티파이 Wrapped처럼 "2026 나의 여행 리캡" 자동 생성 → 공유 유도. 매년 무료로 화제성이 재장전되는 장치. (서버 통계 데이터로 구현 가능)

## 4. 채널별 실행 전략 (예산 0원)

### 4-1. 인스타그램/릴스 — 주력 채널
운영 계정 컨셉: "떠나 공식"이 아니라 **"나루(마스코트)와 떠나는 코스 큐레이션"**.

주간 콘텐츠 루틴 (주 3회, 각 15분 제작):
- **월**: 유저 코스 리그램 + 지역 태그 ("이번 주 인기 코스 TOP3")
- **수**: 앱으로 만든 30초 Vlog 샘플 (자막: "편집 0분")
- **금**: 개발자 비하인드 ("혼자 만드는 여행앱 일지 #N") — 1인 개발 서사는 그 자체로 팔로우 유발 콘텐츠

해시태그 축: #국내여행 #주말데이트 #데이트코스 #여행브이로그 #○○여행 (지역명 로테이션)

### 4-2. ASO (앱스토어 최적화) — 가장 저평가된 무료 채널
- 제목: `떠나 - 여행 브이로그 자동 제작` (검색 키워드가 제목에 있어야 함)
- 서브타이틀/키워드 필드: 여행기록, 브이로그, 데이트코스, 여행일기, 커플앱, 릴스
- 스크린샷 5장 = 스토리 순서: ①"편집 없이 브이로그" 후킹 → ②지도 코스 → ③도착 알림 → ④자동 합성 → ⑤"KISA 선정" 신뢰
- 첫 리뷰 20개 확보: 지인에게 부탁하되 "구체적 사용 후기"로 (별점만 5개짜리 무더기는 오히려 신뢰 하락)

### 4-3. 커뮤니티 시딩 — 초기 100명은 여기서 나온다
- 네이버 카페 (국내여행 카페, 혼행 카페), 인스티즈/더쿠 (여행 게시판), 에브리타임 (대학 MT 시즌), 클리앙·디시 여행갤
- **광고티 내면 즉사.** "1인 개발자인데 이런 앱 만들었어요, 피드백 부탁드려요" 포맷이 유일하게 통한다 — 개발 과정 스샷 포함, 겸손하게, 댓글 전부 답변.
- 디스콰이엇·GeekNews에 제품 스토리 등록 (개발자 커뮤니티는 KISA·아키텍처 서사가 먹힌다)

### 4-4. 네이버 블로그/SEO
"○○ 데이트코스" 검색량은 네이버가 압도적. 공식 블로그에 주 1회 코스 소개 글 (앱 코스 링크 삽입) → 웹 코스 페이지로 연결. 유저 코스를 소개하면 해당 유저가 자기 SNS에 공유하는 2차 효과.

### 4-5. 프레스/인플루언서
OUTREACH_EMAILS.md의 A~F 버전으로 월 10~20통. 기대치: 답장률 5~10%. 기사 1건 = 신뢰 자산 (스토어·랜딩에 "○○ 소개" 배지로 재활용).

## 5. 브랜드 가치 만들기

**브랜드 = 반복 노출되는 일관성.** 지금 정해서 모든 곳에 똑같이 쓸 것:

- **슬로건**: "편집할 시간에 한 번 더 떠나" (또는 "여행은 기록하는 사람의 것")
- **보이스**: 반말 아닌 존댓말, 감탄 아닌 담백 ("~해보세요"보다 "~하면 됩니다"). 개발자의 진정성이 톤의 핵심.
- **비주얼**: tteOrange(#FF6B35) + 나루 마스코트를 모든 접점에 (앱 빈화면·워터마크·SNS·프레스킷). 캐릭터는 스타트업이 가질 수 있는 가장 싼 브랜드 자산.
- **브랜드 서사 3종 세트** (어디서든 이 셋 중 하나로 말한다):
  1. "혼자 만들었다" (사람 이야기)
  2. "편집을 없앴다" (제품 이야기)
  3. "정부가 인프라를 검증했다 — KISA 선정" (신뢰 이야기)
- **하지 말 것**: 이벤트성 반말 밈 따라하기(톤 붕괴), 타 서비스 비방, 과장 ("국내 최초/유일" — 근거 없으면 법적 리스크도 있음)

## 7. 측정 — 이것만 본다 (주 1회, 30분)

| 지표 | 정의 | 초기 목표 |
|------|------|----------|
| 활성화율 | 설치 → 7일 내 Vlog 1개 완성 | 20%+ |
| 공유율 | Vlog 완성 → 외부 공유 | 30%+ |
| 초대 계수 | 유저 1명이 데려오는 신규 (방 초대) | 0.3+ |
| 4주 재방문 | 설치 4주 후 재방문 | 15%+ |
| PRO 전환 | 활성 유저 → 결제 | 2~5% |

측정 방법: 서버 통계 이벤트(이미 있음)에 퍼널 이벤트 추가 (`install→signup→first_session→first_vlog→share`). 외부 툴 없이 관리자 대시보드에 주간 퍼널 위젯 하나면 충분.

## 8. 유료 광고는 언제?

**"공유율 30% + 활성화율 20%"가 나오기 전까지는 1원도 쓰지 말 것.** 그 전의 광고비는 새는 깔때기에 물 붓기다. 조건 충족 후에는 인스타 릴스 광고(앱으로 만든 실제 Vlog를 소재로) 월 10~30만 원 소액 테스트부터 — 소재가 곧 제품 데모라 CPI가 잘 나오는 유형이다.
