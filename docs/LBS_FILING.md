# 위치기반서비스사업자 신고 준비 자료 (떠나 / AERON)

> 「위치정보의 보호 및 이용 등에 관한 법률」(위치정보법)에 따른 신고 준비 문서.
> 관할: 방송통신위원회(중앙전파관리소 접수). 근거 데이터: 실제 tteona 아키텍처.
> ⚠️ 본 문서는 실무 준비용 초안이며, 최종 서식·요건은 방통위/KISA 공식 안내로 확인.

## 1. 신고 유형 판단

떠나는 **개인위치정보를 수집·이용하는 위치기반서비스**를 제공한다:
- 목적지 도착 감지 (본인 위치)
- 그룹 멤버 간 실시간 위치 공유
- 경로·소요시간 계산, 주변 장소 정보

| 구분 | 떠나 해당 여부 |
|------|--------------|
| 위치정보사업자 (개인위치정보를 수집하여 **타 사업자에 제공**) | 원칙적 비해당 — 위치를 외부 사업자에 판매/제공하지 않음 |
| **위치기반서비스사업자** (위치정보를 이용한 서비스 제공) | **해당** → 신고 대상 |

→ **위치기반서비스사업자 신고**가 타깃. (개인위치정보사업까지 하려면 별도 허가/신고 검토, 현재는 불필요)

## 2. 소상공인·1인 창조기업 특례 확인 (위치정보법 제9조의2)

일정 요건의 소상공인·1인 창조기업은 **신고 없이** 위치기반서비스사업 개시가 가능하나,
개시 후 요건을 벗어나면 **1개월 내 신고**해야 한다.

- [ ] AERON이 특례 대상(소상공인/1인 창조기업)인지 확인
- [ ] 특례 대상이면: 개시 가능하되, 매출·상시근로자 요건 이탈 시점 모니터링
- [ ] **권장**: KISA 인프라로 요건이 갖춰진 지금 **정식 신고를 선제 진행** → 지원사업 성과·투자·B2B 영업에서 신뢰 자산으로 활용

## 3. 신고 시 필요한 것 (체크리스트)

- [ ] **위치정보 이용약관** — 이미 보유(web/terms.html 8조), 신고서식에 맞춰 발췌·정리
- [ ] **위치정보 관리적·기술적 보호조치 명세** — 아래 4장 활용

## 4. 위치정보 관리적·기술적 보호조치 명세 (아키텍처 근거)

> 아래는 실제 구현된 조치다. 신고서의 "기술적·관리적 보호조치" 항목에 그대로 활용 가능.

### 4-1. 수집 최소화 및 목적 제한
- 실시간 공유 위치는 **서버에 저장하지 않고 브로드캐스트만** 수행(휘발). 이동경로를 축적하지 않음.
- 정밀 위치 추적은 **여행 세션 진행 중에만** 활성화, 종료 시 중단.
- 백그라운드 위치 전송은 앱이 비활성(scenePhase ≠ active)이면 중단.

### 4-2. 접근통제 및 인증
- 모든 위치 관련 API·WebSocket은 **Firebase ID 토큰 검증** 통과자만 접근.
- 실시간 위치 채널(WebSocket)은 join 시 **토큰 검증 + 해당 방 멤버십 확인** 후에만 입장 — 비멤버의 타인 위치 열람(도청)·사칭 차단.
- 위치는 **같은 그룹(방) 멤버에게만** 공개, 제3자 제공 없음.

### 4-3. 전송·저장 보안
- 전 구간 **TLS/HTTPS** 암호화 전송.
- 서버 인프라: 방화벽, DB는 내부망(10.30.10.170)으로만 접근, SSH는 키 인증 + 비표준 포트(30022).
- 경로 계산용 좌표는 카카오모빌리티에 전달되나 결과는 캐시, 개인 식별정보 미결합.

### 4-4. 이용·제공 사실의 기록·보존 (위치정보법 제16조)
- 개인위치정보의 수집·이용·제공 사실 확인자료를 기록·보존 후 법정 기간 경과 시 파기.
  - [ ] **구현 필요 확인**: 현재 위치 이용 이벤트가 로그로 남는지 점검. 미비 시 최소 이용 로그(누가·언제·어떤 목적) 적재 추가 검토.

### 4-5. 관리적 조치
- 개인위치정보 취급 인력 최소화(1인 운영, 관리책임자=대표).
- 위치정보 관리책임자 지정 및 처리방침 공개(web/privacy.html 12조).
- 이용자 권리: 동의 철회(기기 위치권한 회수), 열람·정정 요청 채널 제공.

## 5. 위치정보 처리 흐름 (신고서 첨부용 요약)

```
[이용자 기기] --(TLS)--> 목적지 도착 감지: 온디바이스 지오펜스 (외부 전송 없음)
[이용자 기기] --(WSS, 토큰+멤버십 검증)--> [WAS] --브로드캐스트--> [같은 방 멤버]
                                             └─ 저장하지 않음(휘발)
[이용자 기기] --(TLS)--> 경로계산 좌표 --> 카카오모빌리티(결과 캐시)
[이용자 기기] --(TLS)--> 장소 좌표 --> TourAPI/Google(사진·정보 조회)
```
