# 떠나(tteona) 유료화 전략 — 흑자 구조 설계

> 원칙: **무료 유저도 핵심 경험(코스 따라가기 → 자동 Vlog)은 끝까지 완성할 수 있어야 한다.**
> 유료는 "더 잘, 더 많이, 더 편하게"에만 붙인다. 기록 자체에 벽을 세우면 플라이휠(코스 생산)이 죽는다.

---

## 수익 구조 전체 그림

떠나의 원가 구조는 이미 이례적으로 유리하다:
- 서버 3대 = KISA 지원 (고정비 ≈ 0)
- 외부 API = PG 캐시로 디커플링 (변동비 ≈ 상수)
- 즉, **월 손익분기점이 사실상 애플 개발자 계정 연 $99 수준** — 구독자 두 자릿수면 흑자다.

수익원은 시간축으로 3단계:

| 단계 | 수익원 | 시작 시점 |
|------|--------|----------|
| 1단계 (지금~) | PRO 구독 + 단건 구매 | 즉시 |
| 2단계 (유저 1천~) | 제휴 커머스 + 지자체 B2B | 3~6개월 |
| 3단계 (유저 1만~) | 크리에이터 마켓 + 데이터 인사이트 | 1년+ |

---

## 1단계 — 소비자 결제 (지금 바로)

### ① tteona PRO 구독 (이미 구현됨 — 최적화 방향)

현재 게이팅 5종(워터마크 제거·멀티포맷·BGM 선택·장편·우선처리)은 방향이 좋다. 보강 포인트:

- **가격 앵커**: 월간을 의도적으로 비싸게(예: ₩4,900), 연간을 "월 ₩2,000대"로 — 연간 전환 극대화. 7일 무료 체험 유지.
- **전환 트리거 최적화**: 페이월을 설정 메뉴가 아니라 **"Vlog 완성 직후"**에 노출하는 게 핵심. 방금 만들어진 내 브이로그에서 워터마크를 지우고 싶은 순간이 지불 의사 최고점이다. "이 Vlog에서 워터마크 빼기 → PRO" 버튼 하나가 설정 페이월 열 개보다 세다.
- **PRO 전용 신기능 로드맵**: AI 하이라이트 편집(서버 8코어 활용), 프리미엄 BGM 팩, 커스텀 인트로/아웃트로, Vlog 화질 4K.

### ② Vlog 싱글 패스 (소비성 IAP) — **신규 추천, 효과 클 것**

한국인 평균 여행 빈도는 연 2~4회. "1년 내내 구독"이 안 맞는 유저가 다수다.
- **"이번 여행만 PRO" — 3일권 ₩3,300** 같은 소비성 상품.
- 구독 거부감이 있는 유저의 결제 진입점이자, 써보고 좋으면 구독으로 올라오는 사다리.
- 서버 게이팅 구조상 구현 비용이 낮다 (기간 한정 entitlement).

### ③ 시즌 한정 콘텐츠 팩
벚꽃 시즌 BGM+타이틀 테마 팩(₩1,100~2,200) 등. 매출보다는 **결제 경험의 심리적 문턱을 낮추는** 역할. 우선순위는 ①② 다음.

## 2단계 — 제휴·B2B (유저 1천 명대부터)

### ④ 제휴 커머스 (어필리에이트) — 원가 0의 수익
코스의 장소들은 곧 소비 지점이다. 코스 상세·세션 화면에서:
- 장소가 액티비티/입장권이면 → 클룩·마이리얼트립 제휴 링크
- 숙소면 → 아고다/야놀자 제휴 링크
- 유저에겐 "예약" 편의 기능으로 보이고, 우리에겐 커미션. **광고처럼 안 보이는 게 생명** — 코스 맥락에 맞는 것만.

### ⑤ 지자체·관광재단 B2B — KISA 선정이 열어주는 문
- **인증 코스 패키지**: 지역 대표 코스 제작+상단 노출+결과 리포트(따라간 여행자 수, 생성된 Vlog 수) — 건당/월간 과금.
- 지역 축제 시즌 기획전 스폰서십.
- KISA 선정 이력이 공공 영업의 신뢰 배지가 된다. 아웃리치 메일 버전 E와 연동.

### ⑥ 스폰서 핀/기획전 (신중하게)
지도에 광고 핀을 꽂는 건 UX 훼손 위험이 커서 비추천. 하되 **탐색 탭 "기획전" 섹션**으로 한정 — "○○카페 브랜드가 제안하는 서울 카페 코스" 같은 네이티브 형태만.

---

## 3단계 — 플랫폼 수익 (유저 1만+)

### ⑦ 크리에이터 유료 코스 마켓
인증 크리에이터(뱃지 시스템 이미 존재)가 프리미엄 코스(상세 팁·예약 정보·숨은 스팟 포함)를 유료 판매 → 수수료 20~30%. 크리에이터에게 수익이 생기는 순간 **코스 공급이 폭발**하는 구조 전환점. 결제는 IAP 규정(디지털 콘텐츠 = 인앱 결제 필수) 유의.

### ⑧ 여행 기록 실물화
연말 "올해의 여행" 자동 편집 영상 + 포토북 주문 제작(외주 인쇄 API 연동). 객단가 높고 감성 적합도 최고. 물리 상품이라 IAP 수수료 30%도 안 붙는다.

### ⑨ 보행 데이터 인사이트 (장기, 신중)
"어느 코스가 실제로 걸어졌는가"는 지자체·상권 분석에 값진 데이터. 단, **개인 식별 불가능한 통계로만**, 개인정보처리방침에 명시 후. (7·8번 과제와 직결)

## 하지 말 것

- ❌ Vlog 생성 자체를 유료화 (핵심 루프 파괴 — 무료로 만들고 '더 좋게'만 유료)
- ❌ 배너 광고 SDK (여행 감성 앱에서 CPM 몇 백 원 벌자고 브랜드를 태우는 짓)
- ❌ 코스 열람 제한 (콘텐츠 유통이 마케팅인데 유통을 막는 자충수)
- ❌ 초기부터 가격 실험 남발 (환불·CS 부담. 가격은 분기 1회만 조정)

## 90일 실행 순서

1. **주 1~2**: 페이월 노출 지점을 "Vlog 완성 직후"로 이동 + A/B용 이벤트 로깅(전환 퍼널 계측)
2. **주 3~4**: Vlog 싱글 패스(3일권) 출시
3. **월 2**: 어필리에이트 1개사(클룩 또는 마이리얼트립) 연동 실험
4. **월 3**: 지자체 제안서 1곳 발송 (아웃리치 E 활용), 전환 데이터 기반 가격 확정
