# 떠나(tteona) BGM 라이선스 트래커

> ⚠️ **왜 중요한가** — 떠나의 BGM은 단순 재생이 아니라 **Vlog에 합성되어 유저의 SNS로 재배포**된다.
> 이는 저작권상 복제·배포·2차적저작물 작성에 해당해, 스트리밍보다 훨씬 넓은 이용허락이 필요하다.
> "무료 다운로드"라도 **상업적 이용·영상 삽입·재배포**가 모두 허용되는지 트랙별로 확인해야 한다.
> 하나라도 조건 불명확하면 그 트랙은 교체하는 것이 안전하다.

---

## 1. 판단 기준 (각 트랙이 모두 ✅ 여야 함)

| 항목 | 확인 질문 | 불충족 시 |
|------|----------|----------|
| 상업적 이용 | 앱(유료 구독 포함)에서 써도 되는가? | 교체 |
| 영상 삽입(sync) | 영상에 배경음악으로 넣어도 되는가? | 교체 |
| 재배포 | 그 영상을 유저가 SNS에 올려도 되는가? | 교체 |
| 크레딧 의무 | 작곡자·출처 표기가 필요한가? | 필요 시 **표기 이행** |
| Content ID | 유튜브 등에서 저작권 클레임이 걸리는 음원인가? | 클레임 트랙은 교체 |

## 2. 트랙 인벤토리 (서버에서 자동 생성 → 여기 붙여넣기)

떠나 BGM은 WAS 서버 `~/tteona-api/assets/bgm/{couple,friends,family,solo}/*.mp3` 에만 존재한다(저장소 미포함). 아래 명령을 **WAS 서버에서 실행**해 현재 트랙 목록과 표 골격을 뽑는다:

```bash
# WAS 접속
ssh -i ~/Downloads/에어론\ 펨키/aeron-was-key.pem -p 30022 ubuntu@114.110.181.49

# 트랙 목록을 마크다운 표로 출력
cd ~/tteona-api/assets/bgm
echo "| 무드 | 파일명 | 출처(사이트) | 상업 | 삽입 | 재배포 | 크레딧 | 확인 |"
echo "|------|--------|-------------|:---:|:---:|:---:|------|:---:|"
for mood in couple friends family solo; do
  [ -d "$mood" ] || continue
  for f in "$mood"/*.mp3; do
    [ -e "$f" ] || continue
    echo "| $mood | $(basename "$f") | ? | ? | ? | ? | ? | ⬜ |"
  done
done
```

> 파일명 규칙이 `{작곡자}-{제목}-{숫자ID}.mp3` 형태다(server.js의 BGM 파싱 로직 기준).
> 숫자 ID가 붙은 명명은 **Pixabay Music·Mixkit 등 무료 라이브러리 다운로드 파일**일 가능성이 높으니,
> 각 트랙을 그 사이트에서 파일명/작곡자로 역검색해 라이선스를 특정하면 빠르다.

### (여기에 위 명령 출력 붙여넣고 채우기)

| 무드 | 파일명 | 출처(사이트) | 상업 | 삽입 | 재배포 | 크레딧 | 확인 |
|------|--------|-------------|:---:|:---:|:---:|------|:---:|
| _(서버 명령 실행 후 채움)_ | | | | | | | ⬜ |

## 3. 안전한 소스 (교체가 필요할 때)

상업적 이용 + 영상 삽입 + 재배포가 명시적으로 허용되는 대표 소스:

| 소스 | 라이선스 특징 | 크레딧 |
|------|--------------|--------|
| **Pixabay Music** | 자체 라이선스 — 상업적 이용·수정·영상삽입 허용, 재판매만 금지 | 불필요(권장) |
| **Mixkit (Free)** | Mixkit Free License — 앱·영상 상업적 이용 허용 | 불필요 |
| **YouTube Audio Library** | 대부분 크레딧 불필요/필요로 명시됨 (트랙별 확인) | 트랙별 상이 |
| **Uppbeat (무료 티어)** | 크레딧 필수, SNS/영상 허용 | **필수** |
| **Epidemic Sound / Artlist (유료 구독)** | 구독 시 광범위 허용 — 규모 커지면 고려 | 불필요 |

> ❌ 피할 것: 출처 불명 "무료 브금" 블로그 파일, 유튜브에서 mp3 추출, "개인적 이용만 무료"인 트랙.

## 4. 크레딧 표기가 필요한 경우 이행 방법

크레딧 의무가 있는 트랙을 쓴다면 다음 중 하나로 표기(둘 다면 더 안전):
1. **Vlog 엔딩 크레딧** — 합성 시 마지막에 "Music: {작곡자} ({출처})" 오버레이 (CALayer로 추가, 서버 파이프라인 수정)
2. **앱 내 고지 페이지** — 설정 → "음악 저작자 표시"에 전체 트랙 크레딧 목록

## 5. 처리 체크리스트

- [ ] WAS에서 트랙 목록 추출 → 위 2번 표 채우기
- [ ] 각 트랙 5개 기준 검증 (하나라도 ✗ → 교체)
- [ ] 크레딧 필수 트랙 식별 → 표기 방식 결정·구현
- [ ] 라이선스 증빙(다운로드 페이지 스크린샷/영수증) 별도 폴더 보관
- [ ] 교체분 반영 후 `/api/vlog/bgm` 응답 확인
- [ ] 이용약관 6조(BGM 권리) 문구와 정합성 확인
